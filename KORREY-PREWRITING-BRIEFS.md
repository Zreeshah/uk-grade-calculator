## Keyword Ownership Rules

1. **Homepage owns the broad university-grade cluster.** It may mention related tools, but does not try to become their full landing pages.
2. **Module, weighted, masters, BTEC, final, GPA, percentage and classification tools each own one distinct practical task.** This prevents cannibalisation.
3. **Each university page owns its university-name modifier plus `grade calculator`.** It supports that branded journey and hands general calculation topics back to their specialist hub.
4. **Guides own explanation queries.** They link readers to a calculator when they need an answer, rather than competing with a tool page for an action query.
5. **About is brand/support only.** It should not target broad calculator terms.
